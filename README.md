Para probar la página, es necesario usar npm install para que se descarguen los módulos oficiales en la carpeta del proyecto y luego usar npm run dev para probar la página en servidor local (como si fuera la extensión Live Server, pero para VITE). Otra opción es usar la página web que dejé en la descripción de este repositorio o aquí: https://hangoutz-eventos.netlify.app/
El código JS se encuentra en src/js
El código CSS se encuentra en src/css
El código HTML se encuentra en la carpeta raíz y es el archivo index.html

Se usó TAILWIND CSS, entonces la mayoría del código de estilos está en el mismo HTML como clases.

La conexión entre HTML y JS fue usando ids, clases y data-sets
